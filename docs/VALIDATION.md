# 验证记录

2026-11-19，本机 Apple Silicon / VOCALOID7 Editor 7.0.0。工程测试仅使用单独复制的编辑器与自制音符工程，没有修改已安装编辑器的文件。

## 已通过

- 最终启动器已实际启动已安装的 `/Applications/VOCALOID7 Editor.app`；菜单栏中文及浏览器开启后的原生布局通过检查。
- arm64 原生动态库与启动器严格编译：`-Wall -Wextra -Werror`。
- 顶部七个原生菜单实际显示中文：“文件、编辑、任务、播放控制、视图、窗口、帮助”；播放子菜单及补丁功能对话框实际汉化；浏览器自绘“声库／网页”标签汉化。
- 五种语言静态覆盖：每种 589/589 个原生资源键、229/229 个 nib 配对文本、123/123 个移植版界面字符串。格式占位符检查通过。这些数字不代表对每个运行时窗口均进行了人工检查。
- 实际选中音符，替换歌词、量化、Swing、生成和声，保存 VPRX 后按 ZIP 内序列核对位置、时值、歌词、音高；撤销仅删除最后一次和声，保留前序操作。
- 实际导出 SVP；再经转换菜单导入，原生编辑器显示 V7 轨道，并允许映射可用声库。源工程的歌手在本机不存在时仍可能出现原生声库映射对话框。
- 自动保存：测试工程由 a/i/u 修改为 a/a/a，定时经 NSDocument 保存完成；磁盘修改时间和序列值核对通过。异步保存有重入保护；打开 sheet、模态窗口、暂存编辑事务时跳过。
- 实际显示音高标签、其他轨道轮廓、圆角音符、SV 波形、图片／GIF／视频立绘；歌词居中运行时几何检查通过。立绘取消后恢复原生绘制。
- 实际音频播放时频谱显示。原生回归额外覆盖仅右声道和反相立体声，避免错误地平均声道而消失。
- 实际 dyld 注入回归：动态库可成为 image 0，必须按 MH_EXECUTE 找主程序；已修复曾由此导致的绘制崩溃。
- 原生断言覆盖原生菜单标题语言切换、中点舍入、八度保留变音、绘制可见区与跨区长音符、缓存失效、SV 分组、预览末次刷新、稳定模块的缓存失效边界。
- 格式转换：27 个格式导出，24 个可读格式往返，MXL、中文拼音、无效选项、拒绝覆盖、伴奏提取生命周期检查。测试范围是代表性三音符与伴奏样本，不保证所有工程字段无损。

## 剩余差异及验证范围

- 独立编辑器加载，AU/VST 宿主尚未接入；Intel 构建尚未实现。
- 和声界面一次一个级数；Windows 多级数同时勾选的交互尚未复刻。
- 属性面板右置：真实 UI 回归仍失败，已从当前菜单和布局 hooks 移除；保留原生面板位置。
- 多种 Windows WPF/.NET 性能补丁尚未逐项等价实现或测量。Mac 使用原生缓存与播放定时器；手动堆回收不等价于释放活跃 PCM。详细证据及清单见 [NATIVE-OPTIONS.md](NATIVE-OPTIONS.md)。
- SV 波形幅度沿用 Mac 原生尺度；生成过程的部分波形仍可暂时显示原生样式。
- V7 专用合成参数、复杂曲线、所有第三方格式在各目标软件中的呈现尚未做全量验证。
- 系统文件选择器和系统自带应用菜单项可能遵循 macOS 语言；七个编辑器菜单及其原生静态条目已经覆盖。

这是一份可运行的移植试用构建，不能表述为 Windows 全功能已经完全等价。
