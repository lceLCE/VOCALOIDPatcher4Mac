## 兼容性与准备

本项目是 macOS 移植试用版，不是编辑器或声库安装包。当前仓库提供源码，需要自行构建。

| 条件 | 要求 |
| --- | --- |
| 电脑 | Apple Silicon Mac；Intel 尚未适配 |
| 系统 | macOS 15 或更新版本 |
| 编辑器 | 已安装、原本能够正常启动的 VOCALOID7 Editor 7.0.0 |
| 原生摘要 | `eb9440ffedc2bcd00f897dab57007767d59a64032e7489c0cf1a5546c1d0ba92` |
| 构建工具 | Git、zsh、Xcode Command Line Tools、uv |
| Python | 由 setup.command 通过 uv 建立本地 Python 3.12 环境 |
| 网络与空间 | 首次下载源码/Python/依赖需要网络；安装会保存完整原版及转换环境，占用额外空间 |

摘要对应完整原生可执行文件，包括 universal 容器，不是单独提取的 arm64 切片。安装模式的外层入口是补丁引导程序；核对版本时使用内部原生文件：

```sh
editor_app='/Applications/VOCALOID7 Editor.app'
if [ -d "$editor_app/Contents/Resources/Native/VOCALOID7 Editor.app" ]; then
  editor_app="$editor_app/Contents/Resources/Native/VOCALOID7 Editor.app"
fi
shasum -a 256 "$editor_app/Contents/MacOS/VOCALOID7 Editor"
```

只显示“7.0.0”不足以证明兼容。不同摘要要按[适配指南](ADAPTING.md)重新核验代码地址、对象字段和 ABI。不要关闭检查来强行运行。

## 首次构建与安装

### 准备工具

安装 Xcode Command Line Tools，可参考 [Apple 官方说明](https://developer.apple.com/documentation/xcode/installing-the-command-line-tools/)：

```sh
xcode-select --install
```

工具已安装时无需重复安装。安装后检查：

```sh
xcrun --find clang
git --version
```

按 [uv 官方安装说明](https://docs.astral.sh/uv/getting-started/installation/)安装 uv。已有 Homebrew 的用户可以使用官方列出的方式：

```sh
brew install uv
```

重新打开终端，确认 `uv --version` 能输出版本号。无需手动把 Python 包安装到系统环境。

### 下载、构建和检查

在本机可写、尽量不受 iCloud 或其他文件同步工具管理的目录中执行：

```sh
git clone https://github.com/lceLCE/VOCALOIDPatcher4Mac.git
cd VOCALOIDPatcher4Mac
./build.command
./conversion/setup.command
./check.command
```

构建生成 `VOCALOIDPatcher.dylib`、`VOCALOID7 Patcher.app` 和 `VOCALOIDPatcherBootstrap`。setup.command 建立 `conversion/.venv` 并安装固定依赖；check.command 执行原生和转换检查。所有命令成功退出后再安装。GitHub 的源码 ZIP 也可用于构建；使用 ZIP 的目录不能直接执行下文的 `git pull`，更新时应另行下载源码。

### 安装到原 V7 图标

1. 保存工程，完全退出 V7。关闭一个工程窗口不一定代表编辑器进程已经退出。
2. 在仓库根目录执行：

```sh
conversion/.venv/bin/python install.py install
```

3. 等待成功输出安装记录，包含应用、备份和补丁目录。
4. 直接从“应用程序”或原 Dock 图标打开 `VOCALOID7 Editor`。
5. 检查顶部是否出现 `VOCALOID Patcher` 菜单，并确认“界面语言”为简体中文。

非默认位置可以指定：

```sh
conversion/.venv/bin/python install.py install --app '/其他本机路径/VOCALOID7 Editor.app'
```

安装与恢复时使用相同路径。保持安装位置不变；移动应用之前先恢复，再在新位置安装。不要把整套命令用 sudo 运行，安装数据是按当前用户保存的；目标目录不可写时，应由具备写权限的账户处理安装。

安装器会核验目标摘要与原签名、保留完整原版、准备并签名新外层应用，验证后再替换。原生可执行文件保留不变。完整结构见[安装说明](INSTALLING.md)。它不会修改编辑器激活逻辑或系统安全设置。

## 日常启动与语言

安装模式下直接打开原来的 `VOCALOID7 Editor.app`。日常不需要终端、源码目录或独立补丁启动器。不要直接打开内部 `Native` 应用或备份副本，它们保存的是原生编辑器。

菜单：**VOCALOID Patcher → 界面语言**。支持简体中文、繁体中文、English、日本語、Español；选择会保存。语言包覆盖菜单、原生文本及补丁对话框，系统文件选择器的一部分界面仍可能跟随 macOS 语言。动态窗口可在刷新或重新打开后更新；并非每个运行时文本均做过人工验证。

## 音符处理

先打开工程，在钢琴窗选中当前乐段中的音符，再使用顶部 `VOCALOID Patcher` 菜单。歌词替换、量化、Swing/Shuffle 都要求选中音符。和声在没有选中音符时会使用当前乐段的全部音符。

这些功能会编辑工程。每次确认会提交一次原生事务；需要取消结果时使用编辑器的撤销。操作失败会尝试回滚本次事务。已有其他编辑事务尚未完成时，先结束当前操作再重试。

### 替换选中音符歌词

入口：**替换选中音符歌词…**。输入一个文本，例如 `la`，所有选中音符都会替换为相同文本。该功能不把一句话逐字分配到不同音符；空文本会取消这次处理。

### 量化选中音符时值

入口：**量化选中音符时值…**。输入 `网格tick,强度百分比`，使用半角逗号：

| 示例 | 含义 |
| --- | --- |
| `120,100` | 把时值调整到十六分音符网格 |
| `240,100` | 使用八分音符网格 |
| `120,50` | 向量化目标移动 50% |

四分音符是 480 tick。网格必须是 1–1920 的整数，强度为 0–100；默认尝试读取当前原生网格。此操作调整**音符时值**，起始位置保留。量化目标至少为一个网格；中点按偶数舍入。

### 生成和声

入口：**生成和声…**。输入 `根音MIDI,音阶步进,轨道模式`，默认 `60,2,1`。

| 字段 | 范围与含义 |
| --- | --- |
| 根音 MIDI | 0–127；例如 60 为 C、62 为 D、65 为 F。算法使用以它为主音的大调自然音阶 |
| 音阶步进 | `2` 到 `7` 或 `-2` 到 `-7`；正值向上，负值向下 |
| 轨道模式 | `1` 新建轨道；`0` 尝试复用时间范围无冲突的其他歌声音轨，找不到则新建 |

**这里的 2 是移动两个音阶步进，即 C→E 的三度；不是“二度音程”。** 在 C 大调中，2/3/4/5/6/7 分别对应三度/四度/五度/六度/七度/八度。

- `60,2,1`：C 大调上方三度，新建轨道。
- `60,-2,1`：C 大调下方三度，新建轨道。
- `60,7,1`：上方八度；八度处理保留原有升降音关系。

每次只生成一个步进，可重复调用。新轨道使用源轨道类型与声库；输出音高限制在 MIDI 0–127。非调内音会按算法映射到邻近音阶位置，建议试听确认。当前没有独立小调/自定义音阶选项，也没有 Windows 版同时勾选多个级数的界面。

### Swing 与 Shuffle

四个入口：**八分音符 Swing / 八分音符 Shuffle / 十六分音符 Swing / 十六分音符 Shuffle**。

Swing 使用约 60:40 的前后分配，Shuffle 使用约 2:1。八分模式按一对八分音符处理，十六分模式按一对十六分音符处理。选中音符的起点和时值都会映射。每点击一次会再次执行编辑；如需回到处理前，用撤销再选择其他模式。

## 钢琴窗显示与立绘

入口：**VOCALOID Patcher → 钢琴窗与立绘**。

| 项目 | 用法 |
| --- | --- |
| 显示音符音高 | 在足够宽高的音符上显示音名；VOCALOID 约定下 MIDI 60 显示 C3。过小的音符不绘制标签，可放大钢琴窗 |
| 显示其他轨道音符 | 显示其他歌声音轨的音符轮廓，供对齐参考 |
| 忽略静音轨道 | 与其他轨道轮廓显示配合，过滤静音轨道 |
| 歌词垂直居中 | 调整原生音符文字的绘制位置 |
| 圆角音符 | 调整原生音符轮廓与填充的圆角 |

这些开关会保存。显示选项不改变音符数据。

### 自定义声库立绘

1. 选中已分配声库的歌声音轨，并打开钢琴窗。
2. 保持原生“声库图片显示”按钮开启。
3. 选择 **为当前声库选择图片或视频…**，选择本机素材。
4. 用 **显示立绘** 开关和下表选项调整效果。

| 设置 | 范围 |
| --- | --- |
| 大小… | 32–1024 像素；实际绘制还受可见区域限制 |
| 不透明度… | 0–100% |
| 水平位置… | 0% 左侧，100% 右侧 |
| 垂直位置… | 0% 上侧，100% 下侧 |

配置按声库标识保存，同一声库可以在不同轨道复用。初次记录默认大小 220、不透明度 90%、靠右下。已实测 PNG、动画 GIF 和 H.264 MP4；其他图片/视频取决于系统解码能力。视频静音循环播放。

设置保存的是素材路径，不会把素材打包进 VPRX。移动或删除素材后请重新选择。**清除当前声库立绘** 会移除该声库的自定义映射并恢复原生绘制。

## 工程格式转换

入口：**VOCALOID Patcher → 工程格式转换**。转换使用本地 LibreSVIP 2.9.2，初次准备依赖需要网络；转换本身在本地运行，原编辑器自身的联网行为不变。

### 导入

选择 **导入其他工程格式…** → 选择文件 → 填写选项或保留 `{}` → 按需勾选中文转拼音 → 转换。编辑器会打开一个新的未保存工程，请及时另存为新的 VPRX。源文件保持不变。

导入到编辑器时默认使用 AI 歌声音轨，并在条件匹配时参考当前声库。来源歌手在本机不存在时，原生声库映射对话框可能要求选择已安装声库。VPR/VPRX 在选项为空且不转拼音时使用原生副本路径，保留原生轨道类型与声库。

### 导出与字幕

打开工程后选择 **导出其他工程格式…**。在保存文件名中写明扩展名，例如 `song.svp`、`song.ustx`、`song.lrc`。随后配置输入/输出选项并转换。导出先生成原生快照，不改变当前工程的保存身份；目标不能是当前工程文件。选择已存在的目标时注意保存面板的替换确认，GUI 导出可以覆盖该目标。

| 类别 | 扩展名 |
| --- | --- |
| 读写转换入口 | `ustx` `ust` `svp` `s5p` `vsq` `vsqx` `vpr` `ccs` `tssln` `acep` `vvproj` `ppsf` `dv` `tlpx` `tlp` `svip` `ds` `aisp` `y77` `vog` `musicxml` `json` `ufdata` `mid` |
| 仅导出字幕 | `lrc` `srt` `ass` |
| 额外导入 | `vprx` |
| 别名 | `xml`/`mxl` 使用 MusicXML，`midi` 使用 MIDI；MXL 可导出为压缩容器 |

共有 27 个转换器入口，VPRX 和别名不额外计入这 27 个。转换器不导出 VPRX；保存 VPRX 请用编辑器正常保存。

### JSON 选项与中文拼音

**查看格式选项…** 中输入 `ust`、`svp`、`vpr` 等扩展名，可查询当前固定版本的字段、类型和默认值。

“导入选项 JSON”对应源格式读取器，“导出选项 JSON”对应目标格式写入器；导入其他格式到编辑器时，目标写入器是 VPR。默认填 `{}`。使用 JSON 双引号，不要添加注释或不认识的字段。

UST 默认编码为 Shift-JIS。读取中文 UST 时，在导入选项填：

```json
{"encoding":"UTF-8"}
```

写出中文 UST 时，在导出选项填同样内容。其他字段以“查看格式选项”返回值为准。切换格式后，旧字段可能不适用，应先重置 `{}` 再重新配置。转换选项和拼音勾选在当前进程中复用，重启后重置。

勾选 **将中文歌词转换为拼音**，会在本次转换中处理中文歌词；原工程文件不会被就地改写。转换器返回的警告会显示在对话框中，需结合目标软件试听/检查。V7 专用参数、复杂音高曲线和全部元数据尚未证明可以无损跨格式保存。

如果完成提示中出现配套音频目录，请连同导出工程一起保留。VPR/VPRX 的内嵌伴奏可能被提取到目标旁边的独立目录，删除它会使导出工程失去对应音频引用。

## 保存与自动保存

**保存工程副本…** 可把当前工程状态写为独立 VPRX 副本。普通保存与另存为继续使用编辑器自己的功能。

**自动保存…**：未开启时点击，输入 1–120 分钟的数值并确认；开启后再次点击即关闭。改变间隔需先关闭再开启。该设置会保留到下次启动。

计时器针对当前可识别工程：已具有保存路径、扩展名为 `.vprx` 且有修改时写回原文件。新建工程或转换导入但尚未另存的工程，先手动保存一次。模态窗口、保存 sheet、未提交事务或尚未结束的自动保存期间会跳过；定时器也可能延后到交互结束再执行。多个打开的工程不会统一批量保存，需要分别管理。

## 频谱与波形选项

**实时输出频谱** 打开/隐藏频谱窗。播放能产生音频的工程后观察；关闭频谱窗会停止其采样观察。它读取编辑器自身输出，不需要系统录音权限；不是系统全部声音的分析器。

**布局与波形** 菜单包含：

| 项目 | 作用 |
| --- | --- |
| V6 深色工具栏与标题栏 | 在已适配的原生工具栏应用 V6 风格配色，关闭可恢复原颜色 |
| 波形不透明度… | 0–100%，仅改变波形显示 |
| SV 样式波形 | 将音高组的波形放到共同基线，幅度沿用 Mac 原生尺度 |
| 合成预览刷新限制为 30 fps | 合并合成预览重绘，保留末次刷新；不代表把整个编辑器或音频引擎限制到 30 fps |
| 释放闲置堆内存 | 请求分配器回收已空闲页；报告 0 MB 也可能正常，不会清空所有活跃 PCM 缓存 |

显示/波形设置会保存。SV 波形在完整渲染数据尚未形成时可能暂用原生显示。属性面板右置已因真实布局回归失败而移除，不在当前菜单提供。

## 设置与备份位置

安装模式以当前用户的下列目录为准：

| 路径（相对 `~/Library/Application Support/VOCALOIDPatcher/`） | 内容 |
| --- | --- |
| `VOCALOID7/` | 补丁动态库、语言包、转换器及本地 Python 环境 |
| `VOCALOID7/settings.plist` | 界面语言、自动保存间隔 |
| `VOCALOID7/drawing-settings.plist` | 钢琴窗显示开关 |
| `VOCALOID7/artwork-settings.json` | 按声库保存的素材路径、大小、透明度、位置 |
| `VOCALOID7/native-options.json` | 工具栏、波形及预览刷新选项 |
| `backups/<id>/` | 安装前完整应用备份，更新时可能还包含之前的补丁内容 |
| `install-records/` | 应用绝对路径与安装/恢复所需摘要及备份位置 |
| `installer/` | 不依赖源码目录的恢复脚本和兼容头文件 |

在 Finder 按 `⌘⇧G` 可以前往上述目录。运行中不要编辑配置；需要重置某项时先退出，再将对应文件改名为 `.bak` 保留一份，重开后使用默认值。不要改名或移走备份、安装记录来强行绕过恢复检查。

安装模式下删除源码目录不会移除已安装补丁，但 uv 管理的 Python 运行时仍是转换环境的一部分，不应随意删除。独立运行模式的配置写在源码/补丁目录，和安装模式的设置是不同位置。

## 更新与恢复

### 更新本补丁

先保存并退出编辑器。从旧源码目录执行恢复，或使用已安装的独立恢复入口；恢复保留设置和备份。然后在 Git 克隆目录运行：

```sh
git pull --ff-only
./build.command
./conversion/setup.command
./check.command
conversion/.venv/bin/python install.py install
```

再从原图标打开确认。`git pull`、构建或修改源码本身都不会自动更新 Application Support 中已安装的副本。再次安装会尝试保留已有四个设置文件；素材本身仍应保留在原位置。

### 升级编辑器

升级/重装之前先恢复原版。新编辑器若摘要变化，不应沿用旧私有地址；等待相应适配或按[开发指南](ADAPTING.md)验证。更新覆盖安装集成后，可能需要重新安装汉化。

### 恢复原版

保存并完全退出 V7，在源码根目录执行：

```sh
conversion/.venv/bin/python install.py restore
```

源码目录不在时，使用安装时留下的恢复文件：

```sh
"$HOME/Library/Application Support/VOCALOIDPatcher/VOCALOID7/conversion/.venv/bin/python" \
  "$HOME/Library/Application Support/VOCALOIDPatcher/installer/install.py" restore
```

自定义应用位置需追加同样的 `--app '…/VOCALOID7 Editor.app'`。恢复会校验当前安装状态及原版备份；若应用已经被外部改动/替换、移动或备份损坏，自动恢复可能拒绝覆盖。请保留当前应用、安装记录和备份，先核对状态再人工处理，不要用强制覆盖或改哈希代替核验。

恢复完成后普通打开应用为原生版本。恢复不会自动删除备份、设置或 Python 环境；如需清理磁盘空间，应在确认恢复成功、所需数据另有备份后，通过 Finder 自行管理这些文件。

## 独立运行模式

不想安装到原应用时，可在构建和环境准备后使用：

```sh
./启动.command
```

或双击构建生成的 `VOCALOID7 Patcher.app`。此模式需要完整源码/补丁目录在一起，且每次都通过该入口启动。**只有在未做直接安装时，普通打开原编辑器才会绕过补丁。** 独立模式不修改原应用；直接安装模式会备份并替换外层应用。两种模式不要同时启动同一个编辑器。

## 故障排查

| 现象 | 检查与处理 |
| --- | --- |
| 重开后没有汉化 | 看是否有 Patcher 菜单；检查是否打开了原图标、内部 Native 或备份副本，确认当前用户已安装。旧独立模式须每次用其入口；直接安装被编辑器更新覆盖后需重新核验安装 |
| 有 Patcher 菜单但语言不对 | 在界面语言选择简体中文，确认配置目录可写；必要时重开窗口/应用 |
| Unsupported editor / 构建不同 | 核对完整原生摘要；版本号相同也不能强行安装 |
| entry point modified / 安装记录已存在 | 不要重复覆盖，先退出并按恢复流程处理已有安装 |
| 要求退出编辑器 | 保存后从应用菜单退出；安装器不会替你结束进程 |
| `uv` 找不到 | 安装 uv 并重新打开终端，确认 `uv --version`；setup 也会检查 Homebrew 常见安装位置 |
| `xcrun` 或编译器找不到 | 完成 Command Line Tools 安装，检查 `xcrun --find clang` |
| 权限不足 | 确认目标和源码目录可写；不要把整套命令改成 sudo 导致写入另一用户的支持目录 |
| FinderInfo / resource fork 签名错误 | 使用本机非同步的原版应用和目录；文件提供器可能重新添加元数据。不要通过关闭签名或系统安全设置绕过 |
| 动态库/转换组件缺失 | 检查 Application Support 的完整安装内容；已安装数据不应只剩一个 app。需要重装时先恢复原版 |
| 转换环境初始化失败 | 检查 uv 和网络，可运行已安装目录中的 `VOCALOID7/conversion/setup.command` 重建；之后重开编辑器 |
| 转换字段或编码报错 | 先把对应 JSON 改为 `{}`，查询当前格式选项；中文 UST 使用 UTF-8 |
| 导入提示声库不可用 | 按原生提示映射到本机已安装声库；转换格式不包含声库安装 |
| 立绘不见了 | 选中歌声音轨，确认原生声库图片按钮和“显示立绘”开启，素材路径仍存在；重新选择素材 |
| 音高标签看不到 | 打开显示开关并放大音符，标签会跳过过小的音符 |
| 自动保存无效 | 工程先另存为 VPRX，确认计时器开启且有修改；对话框/编辑事务会延后，多个工程需分别管理 |
| 频谱不动 | 检查编辑器实际播放/合成输出与静音状态；不播放时没有可分析的新音频 |
| 恢复被拒绝或备份缺失 | 保留现状和记录，核验是否已更新、移动、替换应用；不要直接清理记录或强行覆盖 |
